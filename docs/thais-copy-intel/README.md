# Entrega Thaís — 08/09/2026

A implementação separa fontes publicadas, análise editorial e novas copies. Consulte os três documentos desta pasta para diagnóstico, estruturas e dez rascunhos completos.

## Uso

Abra Perfil → Memória. Dados mostra cobertura e divergências; Copywriting permite selecionar a referência publicada; Documentos contém a análise. A seleção encaminha para Copies. Gerar um novo lote utiliza o fornecedor configurado no app. Os dez rascunhos desta entrega foram escritos sem chamada adicional a esse fornecedor.

## Continuidade

Preserve as fontes originais e os projetos existentes. Obtenha uma transcrição em português da reunião antes de atribuir pedidos ao Tiago. Recupere as nove mídias ausentes antes de considerar o acervo integralmente transcrito. Separe publicação, aprovação editorial e resultados comerciais. Para cada nova copy, mantenha post e versão de referência, fala, direção visual, legenda e CTA. Submeta o lote à revisão editorial de Tiago antes da publicação. Não inferir conversões a partir de visualizações.
